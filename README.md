# Гра "Слон" (Elephant Game) - Урок 18

Цей проєкт створений за допомогою React, TypeScript та Vite. 

## Запуск проєкту

Щоб запустити проєкт локально, виконайте наступні кроки:

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```

## Скрипти

- `npm run dev` — запуск сервера для розробки.
- `npm run build` — компіляція TypeScript та збірка проєкту для продакшену.
- `npm run lint` — перевірка коду за допомогою ESLint.
- `npm run preview` — попередній перегляд зібраного проєкту (production).

## Стек технологій

- [React](https://react.dev/) — бібліотека для створення користувацьких інтерфейсів.
- [TypeScript](https://www.typescriptlang.org/) — сувора типізація для JavaScript.
- [Vite](https://vitejs.dev/) — інструмент для швидкої збірки та розробки.
